# Front-End Learning

前端学习项目仓库

## 项目列表

### 百盛工业辅料商店
- **文件**: [baisheng-shop.html](./baisheng-shop.html)
- **描述**: 机械工业风格的辅料售卖页面，包含完整的动画效果和响应式设计
- **特点**:
  - 深色工业主题，渐变背景与纹理
  - 动态导航栏（旋转齿轮图标、流动光带）
  - 英雄区域（逐字弹出标题、打字机效果）
  - 产品卡片（悬停发光、图标动画）
  - 数据看板（圆形仪表盘、数字滚动动画）
  - 完全响应式，支持移动端
  - 纯CSS + 原生JavaScript，无外部依赖

### 其他学习项目
- **窝瓜的百天挑战**: 前端基础练习
  - 列表、表格、表单等HTML基础

## 技术栈
- HTML5
- CSS3 (Animations, Transforms, Gradients)
- JavaScript (ES6+)
- SVG Graphics
